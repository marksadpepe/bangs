# Notch-утилита для Claude Code — спецификация

Личная macOS-утилита (MacBook Air M2, Terminal.app). Подсвечивает «чёлку», когда чат Claude Code
закончил работу или ждёт ответа, а по клику раскрывает из чёлки панель со списком сессий и чатов.

Дизайн — в папке `design/`. Это исходники артбордов в формате `.dc.html`: обычная HTML-разметка
с inline-стилями + класс `Component` с логикой состояний в `<script type="text/x-dc">`.
Сами по себе в браузере они не откроются (нужен рантайм редактора) — читай их как точную
спецификацию: размеры, цвета, отступы, тексты на двух языках, переходы между состояниями.
Скриншоты экранов — в `screenshots/` (если положены).

- `design/Main.dc.html` — панель: список, экран ожидающего чата, настройки. Главный источник.
- `design/States.dc.html` — состояния закрытой чёлки.

## Стек

- Swift + SwiftUI, AppKit там, где нужно окно поверх всего.
- Приложение без иконки в Dock (`LSUIElement = YES`), автозапуск через `SMAppService`.
- Окно: `NSPanel` без рамки, `level = .statusBar`, `collectionBehavior = [.canJoinAllSpaces, .stationary, .fullScreenAuxiliary]`,
  прозрачный фон, без тени системы (тень рисуем сами).
- Позиция и размер выреза: `NSScreen.main.safeAreaInsets.top` и `auxiliaryTopLeftArea` / `auxiliaryTopRightArea`
  — ширина выреза = ширина экрана − обе вспомогательные области. Если чёлки нет (внешний монитор) — рисовать
  такую же «пилюлю» по центру верхнего края.

## Источник событий: хуки Claude Code

В `~/.claude/settings.json` (и в каждой `CLAUDE_CONFIG_DIR`, если аккаунтов несколько) добавить хуки
`Stop`, `Notification`, `UserPromptSubmit`, `SessionStart`, `SessionEnd`. Все вызывают один скрипт
`~/.local/bin/notch-hook`, который читает JSON из stdin, дописывает поля и отдаёт приложению.

Поля от Claude Code: `session_id`, `transcript_path`, `cwd`, `hook_event_name`, для Notification — `message`.
Скрипт добавляет:
- `tty`: `"/dev/$(ps -o tty= -p $PPID | tr -d ' ')"` — для перехода в нужную вкладку Terminal.
- `config_dir`: `${CLAUDE_CONFIG_DIR:-$HOME/.claude}` — чтобы знать аккаунт.
- `ts`: время события.

Доставка в приложение: POST на `http://127.0.0.1:<порт>/event` (приложение поднимает локальный сервер),
fallback — запись файла в `~/Library/Application Support/<App>/inbox/` с `DispatchSource` на папку.
Хук не должен тормозить Claude Code: таймаут 1 с, ошибки молча игнорировать.

Перед реализацией сверь точные имена событий и поля с актуальной документацией хуков Claude Code.

## Модель данных

- **Сессия (островок)** = проект, группировка по `cwd`. Имя — последний компонент пути, путь — с `~`.
- **Чат** = `session_id`. Название — первое сообщение пользователя из `transcript_path` (обрезать до ~40 символов).
- **Статусы чата:**
  - `working` — после `UserPromptSubmit`/`SessionStart`. Серая пульсирующая точка, «работает · N мин».
  - `done` — после `Stop`. Цвет «готово», плашка «Готово», подсветка чёлки.
  - `waiting` — после `Notification` (запрос разрешения / ввода). Цвет «ждёт», плашка «Ждёт тебя», стрелка.
  - `waitSeen` — открыл ожидающий чат и вернулся, но не ответил. Тусклая точка с обводкой, «видел · ждёт ответа». Чёлку не подсвечивает.
  - `denied` — ответил «Нет» из панели. «отклонено · ответь в терминале».
  - `seen` — просмотрен. Полая серая точка.
- Новый `UserPromptSubmit` по чату всегда возвращает его в `working`. `SessionEnd` — удаляет чат через ~10 мин.

## Поведение

- Закрытая чёлка: если есть `done` → пульсирующее свечение цветом «готово» + счётчик справа от камеры.
  Иначе если есть `waiting` → статичный контур цветом «ждёт» + мигающий счётчик. Иначе — обычная чёлка.
- Клик по чёлке — раскрытие панели (спружинить из чёлки, ~250 мс). Клик вне панели или Esc — закрыть.
- Клик по `done` → `seen` (и опционально перевод в терминал — оставить настройкой).
- Клик по `waiting`/`waitSeen`/`denied` → экран чата: последнее сообщение Claude, запрос (команда или вопрос),
  варианты ответа с горячими клавишами 1/2/3, кнопка «Открыть в терминале», стрелка «назад».
  «Назад» и «Открыть в терминале» → `waitSeen`, НЕ `seen`.
- Ответ из панели — **v2**. В v1 кнопки ответа можно показать неактивными или скрыть и оставить только
  «Открыть в терминале». Для v2 проверить, умеет ли хук разрешений возвращать allow/deny.
- `prefers-reduced-motion` / «Уменьшить движение» → без анимаций.

## Переход в терминал (Terminal.app)

```applescript
tell application "Terminal"
  repeat with w in windows
    repeat with t in tabs of w
      if tty of t is "<tty>" then
        set selected of t to true
        set index of w to 1
        activate
        return
      end if
    end repeat
  end repeat
end tell
```
Если вкладка не найдена — открыть новую в `cwd` и выполнить `claude --resume <session_id>`
(с `CLAUDE_CONFIG_DIR`, если он был). Нужен `NSAppleEventsUsageDescription` в Info.plist.

## Аккаунт

Шапка панели, левое «ухо»: `✳ Claude Code · <имя>`, тултип — имя и email. Данные — из `<config_dir>/.claude.json`
(блок `oauthAccount`; сверь имена полей на своей машине). Если активных аккаунтов больше одного — опционально
маленький чип «инициал · имя аккаунта» в заголовке островка вместо сводки по статусам.

## Настройки

Тема (тёмная/светлая), язык (RU/EN), цвет «готово» и цвет «ждёт» — палитры и значения по умолчанию в
`renderVals()` из `Main.dc.html`. Хранить в `UserDefaults`. Верхняя полоса панели всегда чёрная (продолжение чёлки).

## Порядок работы

1. Каркас приложения + окно у чёлки, статичная панель по дизайну с моковыми данными.

3. Свечение чёлки и анимация раскрытия.
4. Экран ожидающего чата и переход в Terminal.
5. Настройки, i18n, аккаунт.
